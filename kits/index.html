FIRST USE

One example you can reproduce

Download the Creative Studio executable ZIP from the public alpha release, extract it and follow the documented self-test before running a synthetic demonstration.

python -I -B run.py --operation self-test
python -I -B run.py --operation demo --to ../creative-production-demo

The demonstration generates JSON, CSV and a textual HTML storyboard; it is not an animation renderer or model-backed assistant. Requires Python 3.12+.
