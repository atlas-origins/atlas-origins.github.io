TRY IT

Two local examples

From the V1 source checkout, using Python 3.12 or newer:

python -B tools/muse_collection.py demo data-engineer
python -B examples/daily_desk.py

The data example reports results from supplied inputs. Daily Desk creates three tasks and two notes in a disposable database, then checks edits, export and restoration. No paid API is required for these local demonstrations.
